볕조각 개인정보 처리방침

시행일: 2026년 11월 2일 (앱 0.22.1부터)

볕조각(이하 "앱")의 개발자 김민창(이하 "개발자")은 「개인정보 보호법」 제30조에 따라 다음과 같이 개인정보 처리방침을 수립·공개합니다.

제1조 처리하는 개인정보

  1. 앱에는 회원가입·로그인 기능이 없으며, 개발자는 이름, 이메일, 전화번호, 위치, Android ID를 수집하지 않습니다.
  2. 개발자는 앱을 설치한 기기를 구별하기 위해 앱이 처음 실행될 때 만드는 임의의 값(이하 "설치 ID")과, 그 설치의 일별 이용 기록(제2조)을 수집합니다. 설치 ID는 광고 ID나 기기 정보에서 만들지 않으며 이름 등 다른 정보와 결합하지 않습니다.
  3. 이용자가 앱의 동의 화면 또는 설정에서 "허용"한 경우에만(개발자가 서버에서 광고 측정을 켜 둔 경우에 한함), 앱에 포함된 Meta 앱 이벤트 도구가 광고 ID와 앱 이용 기록을 Meta에 전송합니다. 허용하기 전에는 이 도구가 실행되지 않고 Meta로 아무것도 전송되지 않습니다(제7조, 제12조).
  4. 사진은 기기 안에서만 처리되며 서버로 전송되지 않습니다. 단, 이용자가 버그 제보에서 “화면 첨부”를 직접 선택한 경우에 한해 그때의 앱 화면 1장이 전송됩니다(제2조의2).
  5. 개발자의 서버는 접속자의 IP 주소를 이용하거나 기록하지 않습니다.

제2조 서버로 전송되는 정보

앱은 아래 정보를 개발자의 서버(Cloudflare)로 전송합니다. 모두 특정 개인을 알아볼 수 없는 정보입니다.

구분 전송 정보 이용 목적 보관 기간
필름 목록 확인 없음 (공개 파일 다운로드) 새 필름 및 필름 정보 갱신 보관하지 않음
사용 통계 필름별 일일 사용 횟수, 앱 버전, Android 버전, 기기 종류, 기기 언어 설정상의 국가 필름 구성 및 서비스 개선 일별 합계로 보관
설치 분석 설치 ID, 처음 실행한 날짜, 설치 경로(Google Play 설치 리퍼러의 utm_source·utm_medium·utm_campaign·utm_content·utm_term 값), 앱 버전, 배포 경로, 기기 언어 설정(예: ko-KR)과 그 국가, 날짜별 횟수(앱 열기, 첫 현상, 필름 보기, 촬영, 저장, 공유, 구매 화면 열기, 구매, 체험 시작, 선물 코드 등록, 네컷·겹찍이 촬영)와 날짜별 구매한 상품 ID 설치 경로·이용 흐름·재방문 분석, 서비스 개선 400일 보관 후 설치 ID 없는 합계로만 보관
버그 제보 이용자가 쓴 제보 내용, 선택한 경우 앱 화면 사진 1장, 앱·기기·화면 정보, 사용 중인 필름, 카탈로그 버전, 기기 언어 설정, 앱의 최근 동작 기록 (제2조의2) 앱 오류 확인 및 수정 받은 날부터 180일
선물 코드 이용자가 입력한 선물 코드, 등록 시각, 등록할 때마다 새로 만드는 임의값 선물 코드 확인 및 지급 코드 유효기간 종료 시까지
  • 사용 통계는 하루 한 번 자동으로 전송되며, 이용자를 구별할 수 있는 정보는 포함되지 않습니다.
  • 설치 분석은 처음 실행할 때 한 번, 그 뒤로 하루 한 번 자동으로 전송됩니다. 사진, 이름, 위치, 광고 ID는 포함되지 않습니다.
  • 선물 코드는 이용자가 직접 입력한 경우에만 전송됩니다.
  • 버그 제보는 이용자가 직접 보낼 때만 전송됩니다.

제2조의2 버그 제보

이용자가 설정의 “버그 제보”에서 내용을 쓰고 보내기를 누른 경우에만 아래 정보가 전송됩니다.

  1. 전송되는 정보: 이용자가 쓴 내용; “화면 첨부”를 선택한 경우에만 설정을 열기 직전의 앱 화면 사진 1장(앱 화면만이며 갤러리 사진은 전송하지 않음); 앱 버전, Android 버전, 기기 제조사·모델; 화면 정보(접힘 상태, 화면 크기, 가로·세로, 화면 배치, 회전 잠금); 사용 중인 필름, 필름 목록(카탈로그) 버전, 기기 언어 설정; 앱이 스스로 남긴 최근 동작 기록(최대 200줄, 파일 경로와 이메일 형태의 문자열은 기기와 서버에서 모두 지움).
  2. 전송·저장하지 않는 정보: IP 주소(서버는 접속자의 IP를 저장하지 않음), 설치 ID, 계정, 광고 ID, 위치.
  3. 이용 목적: 앱 오류의 확인과 수정에만 이용하며 제3자에게 제공하지 않습니다.
  4. 보관 기간: 받은 날부터 180일이 지나면 자동으로 삭제합니다.
  5. 제보 내용에 개인정보를 쓰지 않도록 주의해 주세요. 보낸 제보의 삭제를 원하면 제10조의 방법으로 요청할 수 있습니다.

제3조 기기에 저장되는 정보

  1. 촬영한 사진은 기기의 Pictures/Sunmini 폴더에, 재현상을 위한 원본은 앱 전용 저장공간에 저장됩니다.
  2. 설정, 보유 필름, 체험 횟수, 아직 전송되지 않은 사용 통계(최대 7일)와 설치 분석(설치 ID, 설치 경로, 최대 10일의 횟수), 아직 보내지 못한 버그 제보(최대 5건, 전송되면 삭제)는 기기에 저장됩니다. 설치 ID는 앱을 삭제하거나 앱 데이터를 지우면 함께 삭제되고, 다시 설치하면 새로 만들어집니다.
  3. 등록한 선물 정보는 앱 재설치 시 복원될 수 있도록 Android 자동 백업(Google 계정)에 포함됩니다.
  4. 앱을 삭제하면 앱 전용 데이터는 모두 삭제됩니다. 사진 보관함에 저장된 사진은 이용자가 직접 삭제할 때까지 유지됩니다.

제4조 앱 권한

권한 목적
카메라 사진 촬영
인터넷 필름 목록 확인, 사용 통계·설치 분석 전송, 버그 제보, 선물 코드 등록, 결제, Meta 앱 이벤트
결제 Google Play 인앱 결제
광고 ID Meta 앱 이벤트의 광고 성과 측정 (이용자가 허용한 경우에만 사용)

저장공간, 사진·미디어, 위치 권한은 요청하지 않습니다. 사진 불러오기는 Android 시스템 사진 선택기를 사용하며, 이용자가 선택한 사진에만 접근합니다.

제5조 결제

  1. 유료 필름의 결제는 Google Play가 처리합니다.
  2. 개발자는 결제 수단, 이름, 이메일 등 결제 정보를 제공받지 않습니다.
  3. 결제 정보는 Google 개인정보처리방침에 따라 처리됩니다.

제6조 처리 위탁 및 국외 이전

서비스 운영을 위해 아래 사업자에게 정보를 국외로 이전합니다. 각 사업자별 이전 내용은 다음과 같습니다. 받는 자의 연락처는 각 사업자가 공개한 개인정보 처리방침 페이지입니다.

1. Cloudflare, Inc. (처리 위탁·보관)

구분 내용
이전되는 개인정보 항목 제2조의 사용 통계, 설치 분석(설치 ID 포함), 버그 제보, 선물 코드 정보. 필름 목록 확인은 공개 파일 요청이며 개발자는 전송 항목이 없습니다.
이전 국가·시기·방법 미국 등 Cloudflare의 서버. 앱 사용 중 HTTPS로 전송합니다(사용 통계·설치 분석은 처음 실행할 때와 하루 한 번, 버그 제보·선물 코드는 이용자가 직접 보낼 때).
받는 자의 명칭·연락처 Cloudflare, Inc. — https://www.cloudflare.com/privacypolicy/
이용 목적·보유 기간 필름 목록 제공, 사용 통계·설치 분석·버그 제보·선물 코드 서버 운영. 보유 기간은 제2조의 표와 같습니다.
거부 방법·절차·효과 사용 통계·설치 분석은 앱 설정에서 끌 수 없습니다. 원하지 않으면 앱을 삭제해 주세요(설치 ID가 함께 삭제됩니다). 버그 제보와 선물 코드는 이용자가 보내지 않으면 전송되지 않으며, 보내지 않아도 다른 기능에는 영향이 없습니다. 이미 보낸 정보의 삭제·처리정지는 제10조에 따라 요청할 수 있습니다.

2. GitHub, Inc. (처리 위탁)

구분 내용
이전되는 개인정보 항목 필름 목록(공개 파일) 요청. 앱이 보내는 개인정보 항목은 없으며, 연결 과정에서 기기의 IP 주소가 GitHub에 전달될 수 있습니다.
이전 국가·시기·방법 미국. 주 서버(Cloudflare)에 연결하지 못했을 때에 한해 필름 목록을 확인하며 HTTPS로 요청합니다.
받는 자의 명칭·연락처 GitHub, Inc. — https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement
이용 목적·보유 기간 필름 목록 예비 서버 운영. 개발자는 이 요청에서 얻은 정보를 보관하지 않으며, GitHub의 보유 기간은 GitHub의 정책에 따릅니다.
거부 방법·절차·효과 별도의 거부 절차는 없습니다. 원하지 않으면 앱을 삭제해 주세요. 필름 목록 확인이 되지 않으면 새 필름 정보가 갱신되지 않을 뿐 이미 있는 필름은 계속 쓸 수 있습니다.

3. Google LLC (결제·자동 백업)

구분 내용
이전되는 개인정보 항목 유료 필름 결제 과정의 결제 정보(Google Play가 직접 처리하며 개발자는 받지 않음), 자동 백업에 포함된 등록한 선물 정보(제3조).
이전 국가·시기·방법 미국 등 Google의 서버. 결제할 때, 그리고 Android 자동 백업이 켜져 있을 때 Google 계정으로 전송됩니다.
받는 자의 명칭·연락처 Google LLC — https://policies.google.com/privacy
이용 목적·보유 기간 인앱 결제 처리, 앱 재설치 시 선물 정보 복원. 보유 기간은 Google의 정책에 따릅니다.
거부 방법·절차·효과 결제는 이용자가 구매 버튼을 눌러야 시작됩니다. 자동 백업은 Android 설정에서 끌 수 있으며, 끄면 재설치 시 선물 정보가 복원되지 않습니다.

4. Meta Platforms, Inc. (제3자 제공, 이용자 동의에 따름)

구분 내용
이전되는 개인정보 항목 제7조의 표와 같습니다(광고 ID, 앱 이용·구매 기록 등).
이전 국가·시기·방법 미국. 이용자가 "허용"한 뒤 앱이 실행되는 동안, Meta SDK가 인터넷으로 자동 전송합니다. 허용하기 전에는 전송하지 않습니다.
받는 자의 명칭·연락처 Meta Platforms, Inc. — https://www.facebook.com/privacy/policy
이용 목적·보유 기간 광고 성과 측정. 보유 기간은 Meta의 정책에 따름.
거부 방법·절차·효과 동의 화면에서 "허용 안 함"을 누르거나, 설정의 "광고 측정 데이터 전송"을 끄면 됩니다(제12조). 거부해도 앱 기능은 모두 동일하게 쓸 수 있으며, 끄는 즉시 이후 전송이 중단됩니다.

제7조 제3자 제공

이용자가 허용한 경우에만 앱에 포함된 Meta SDK가 아래 정보를 Meta Platforms, Inc.(미국)에 전송합니다(개발자가 서버에서 광고 측정을 켜 둔 경우에 한함). 그 밖에는 이용자의 정보를 제3자에게 제공하지 않습니다.

동의 방식

  • 앱은 첫 현상 이후(0.22.1로 업데이트한 경우에는 업데이트 후 처음 카메라 화면이 열릴 때) 한 번, 동의 화면을 보여 줍니다. 화면에는 보내는 정보, 받는 자, 목적이 적혀 있고, "허용"과 "허용 안 함" 두 버튼이 같은 크기로 있습니다.
  • "허용"을 누르기 전에는 Meta SDK가 실행되지 않으며 광고 ID도 읽지 않고 Meta로 아무것도 전송되지 않습니다. "허용 안 함"을 누르거나 화면을 닫아도 앱은 똑같이 쓸 수 있습니다.
  • 앱 0.19.0~0.22.0은 별도의 동의 화면 없이, 서버에서 켜진 경우 전송했습니다. 이 버전을 쓰던 이용자도 동의한 것으로 보지 않으며, 업데이트 후 같은 동의 화면을 보게 됩니다.
  • 동의 여부는 이용자의 기기에만 저장되며 개발자의 서버로 전송하지 않습니다.
받는 자 항목 목적 보유 기간
Meta Platforms, Inc. (미국, 앱이 실행 중일 때 인터넷으로 전송) 광고 ID, 앱 실행, 첫 현상, 구매 화면을 연 필름 ID, 구매 시작·완료(상품 ID, Google Play의 가격과 통화), 체험 시작한 필름 ID, 기기·앱 정보(Meta SDK가 자동으로 수집하는 항목) 광고 성과 측정 및 광고 최적화 Meta의 데이터 정책에 따름
  • 사진, 이름, 이메일, 위치, 이용자가 입력한 글은 Meta에 전송하지 않습니다.
  • 이용자가 설정에서 끄거나 개발자가 서버에서 끄면 즉시 전송하지 않습니다(제12조).

제8조 정보의 파기

  1. 보관 기간이 끝난 정보는 지체 없이 복구할 수 없는 방법으로 삭제합니다.
  2. 사용 통계는 일별 합계로만 보관되며, 개인을 식별할 수 없습니다.
  3. 설치 분석은 400일이 지나면 설치 ID 없이 날짜·설치 경로·국가별 합계로만 남기고 원래 기록은 삭제합니다.
  4. 버그 제보는 받은 날부터 180일이 지나면 첨부된 화면 사진과 함께 삭제합니다.

제9조 안전성 확보 조치

  1. 서버와의 모든 통신은 HTTPS로 암호화합니다.
  2. 필름 목록과 선물 정보는 전자서명을 검증한 후 사용합니다.
