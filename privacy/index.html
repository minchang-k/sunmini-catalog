볕조각 개인정보 처리방침

시행일: 2026년 10월 6일 (앱 0.20.0부터)

볕조각(이하 "앱")의 개발자 김민창(이하 "개발자")은 「개인정보 보호법」 제30조에 따라 다음과 같이 개인정보 처리방침을 수립·공개합니다.

제1조 처리하는 개인정보

  1. 앱에는 회원가입·로그인 기능이 없으며, 개발자는 이름, 이메일, 전화번호, 위치, Android ID를 수집하지 않습니다.
  2. 개발자는 앱을 설치한 기기를 구별하기 위해 앱이 처음 실행될 때 만드는 임의의 값(이하 "설치 ID")과, 그 설치의 일별 이용 기록(제2조)을 수집합니다. 설치 ID는 광고 ID나 기기 정보에서 만들지 않으며 이름 등 다른 정보와 결합하지 않습니다.
  3. 개발자가 서버에서 광고 사용 여부를 켠 경우, 앱에 포함된 Meta 앱 이벤트 도구가 광고 ID와 앱 이용 기록을 Meta에 전송합니다(제7조, 제12조).
  4. 사진은 기기 안에서만 처리되며 서버로 전송되지 않습니다. 단, 이용자가 버그 제보에서 "화면 첨부"를 직접 선택한 경우에 한해 그때의 앱 화면 1장이 전송됩니다(제2조의2).
  5. 개발자의 서버는 접속자의 IP 주소를 이용하거나 기록하지 않습니다.

제2조 서버로 전송되는 정보

앱은 아래 정보를 개발자의 서버(Cloudflare)로 전송합니다. 모두 특정 개인을 알아볼 수 없는 정보입니다.

  • 사용 통계는 하루 한 번 자동으로 전송되며, 이용자를 구별할 수 있는 정보는 포함되지 않습니다.
  • 설치 분석은 처음 실행할 때 한 번, 그 뒤로 하루 한 번 자동으로 전송됩니다. 사진, 이름, 위치, 광고 ID는 포함되지 않습니다.
  • 선물 코드는 이용자가 직접 입력한 경우에만 전송됩니다.
  • 버그 제보는 이용자가 직접 보낼 때만 전송됩니다.

제2조의2 버그 제보

이용자가 설정의 "버그 제보"에서 내용을 쓰고 보내기를 누른 경우에만 아래 정보가 전송됩니다.

  1. 전송되는 정보: 이용자가 쓴 내용; "화면 첨부"를 선택한 경우에만 설정을 열기 직전의 앱 화면 사진 1장(앱 화면만이며 갤러리 사진은 전송하지 않음); 앱 버전, Android 버전, 기기 제조사·모델; 화면 정보(접힘 상태, 화면 크기, 가로·세로, 화면 배치, 회전 잠금); 사용 중인 필름, 필름 목록(카탈로그) 버전, 기기 언어 설정; 앱이 스스로 남긴 최근 동작 기록(최대 200줄, 파일 경로와 이메일 형태의 문자열은 기기와 서버에서 모두 지움).
  2. 전송·저장하지 않는 정보: IP 주소(서버는 접속자의 IP를 저장하지 않음), 설치 ID, 계정, 광고 ID, 위치.
  3. 이용 목적: 앱 오류의 확인과 수정에만 이용하며 제3자에게 제공하지 않습니다.
  4. 보관 기간: 받은 날부터 180일이 지나면 자동으로 삭제합니다.
  5. 제보 내용에 개인정보를 쓰지 않도록 주의해 주세요. 보낸 제보의 삭제를 원하면 제10조의 방법으로 요청할 수 있습니다.

제3조 기기에 저장되는 정보

  1. 촬영한 사진은 기기의 Pictures/Sunmini 폴더에, 재현상을 위한 원본은 앱 전용 저장공간에 저장됩니다.
  2. 설정, 보유 필름, 체험 횟수, 아직 전송되지 않은 사용 통계(최대 7일)와 설치 분석(설치 ID, 설치 경로, 최대 10일의 횟수), 아직 보내지 못한 버그 제보(최대 5건, 전송되면 삭제)는 기기에 저장됩니다. 설치 ID는 앱을 삭제하거나 앱 데이터를 지우면 함께 삭제되고, 다시 설치하면 새로 만들어집니다.
  3. 등록한 선물 정보는 앱 재설치 시 복원될 수 있도록 Android 자동 백업(Google 계정)에 포함됩니다.
  4. 앱을 삭제하면 앱 전용 데이터는 모두 삭제됩니다. 사진 보관함에 저장된 사진은 이용자가 직접 삭제할 때까지 유지됩니다.

  3. 결제 정보는 Google 개인정보처리방침에 따라 처리됩니다.

제7조 제3자 제공

개발자가 서버에서 Meta 앱 이벤트를 켠 경우, 앱에 포함된 Meta SDK가 아래 정보를 Meta Platforms, Inc.(미국)에 전송합니다. 그 밖에는 이용자의 정보를 제3자에게 제공하지 않습니다.

받는 자 항목 목적 보유 기간
Meta Platforms, Inc. (미국, 앱이 실행 중일 때 인터넷으로 전송) 광고 ID, 앱 실행, 첫 현상, 구매 화면을 연 필름 ID, 구매 시작·완료(상품 ID, Google Play의 가격과 통화), 체험 시작한 필름 ID, 기기·앱 정보(Meta SDK가 자동으로 수집하는 항목) 광고 성과 측정 및 광고 최적화 Meta의 데이터 정책에 따름
  • 사진, 이름, 이메일, 위치, 이용자가 입력한 글은 Meta에 전송하지 않습니다.
  • 개발자가 서버에서 끄면 이후 실행부터 전송하지 않습니다.

제8조 정보의 파기

  1. 보관 기간이 끝난 정보는 지체 없이 복구할 수 없는 방법으로 삭제합니다.
  2. 사용 통계는 일별 합계로만 보관되며, 개인을 식별할 수 없습니다.
  3. 설치 분석은 400일이 지나면 설치 ID 없이 날짜·설치 경로·국가별 합계로만 남기고 원래 기록은 삭제합니다.
  4. 버그 제보는 받은 날부터 180일이 지나면 첨부된 화면 사진과 함께 삭제합니다.

제9조 안전성 확보 조치

  1. 서버와의 모든 통신은 HTTPS로 암호화합니다.
  2. 필름 목록과 선물 정보는 전자서명을 검증한 후 사용합니다.
  3. 서버 관리 화면은 개발자만 접근할 수 있도록 인증으로 보호합니다.

제10조 이용자의 권리

  1. 이용자는 언제든지 개인정보의 열람, 정정, 삭제, 처리정지를 요구할 수 있습니다.
  2. 요청은 아래 개인정보 보호책임자에게 이메일로 할 수 있으며, 지체 없이 조치합니다.
  3. 앱에는 계정이 없으므로 계정 삭제 절차는 해당하지 않습니다. 앱을 삭제하거나 앱 데이터를 지우면 설치 ID가 삭제되어 이후의 기록은 이전 기록과 연결되지 않습니다.
  4. 광고 ID는 Android 설정(설정 > 개인정보 보호 > 광고 등)에서 재설정하거나 삭제할 수 있습니다.

제11조 아동의 개인정보

앱은 만 14세 미만 아동의 개인정보를 수집하지 않습니다.

제12조 행태정보의 수집·이용·제공 및 거부

  1. 개발자가 서버에서 Meta 앱 이벤트를 켠 경우, 앱의 Meta SDK가 제7조의 이용 기록(행태정보)과 광고 ID를 앱 실행 중 자동으로 Meta에 전송합니다.
  2. 목적은 광고 성과 측정과 광고 최적화이며, Meta가 맞춤형 광고에 이용할 수 있습니다.
  3. 이용자는 Android 설정에서 광고 ID를 재설정·삭제하거나 맞춤 광고를 끌 수 있습니다.
  4. 만 14세 미만 아동을 대상으로 한 맞춤형 광고에 행태정보를 이용하지 않습니다.

제12조의2 해당 없는 사항

다음 사항은 해당하지 않습니다.

  • 민감정보 및 가명정보의 처리
  • 쿠키 등 자동 수집 장치의 설치·운영(웹 쿠키)
  • 자동화된 결정
  • 영상정보처리기기의 운영
  • 국내대리인의 지정

Sunmini Privacy Policy

Effective date: October 6, 2026 (app 0.20.0 onwards)

Minchang Kim (the "Developer"), the developer of Sunmini (the "App"), establishes and discloses this Privacy Policy in accordance with Article 30 of the Personal Information Protection Act of Korea. The Korean version prevails in case of any discrepancy.

1. Personal Information

  1. The App has no sign-up or login. The Developer does not collect names, email addresses, phone numbers, location or the Android ID.
  2. To tell installations apart, the Developer collects a random value the App creates on its first launch (the "install ID") and that installation's daily usage records (Section 2). The install ID is not derived from the advertising ID or device information and is not combined with a name or other information.
  3. When the Developer turns it on on the server, the Meta app events tool inside the App sends the advertising ID and app usage records to Meta (Sections 7 and 12).
  4. Photos are processed only on the device and are never sent to a server, except one picture of the App's own screen when the user ticks "Attach screen" in a bug report (Section 2-2).
  5. The Developer's servers do not use or record the IP addresses of connecting devices.

2. Information Sent to the Server

The App sends the following information to the Developer's server (Cloudflare). None of it identifies an individual.

  • Usage statistics are sent automatically once a day and contain nothing that distinguishes users.
  • Install analytics are sent automatically once on the first launch and then once a day. They contain no photos, name, location or advertising ID.
  • Gift codes are sent only when the user enters one.
  • Bug reports are sent only when the user sends one.

2-2. Bug Reports

Only when the user writes a report under Settings → "Report a bug" and taps send, the following is sent.

  1. Sent: the text the user wrote; only if "Attach screen" is ticked, one picture of the App screen as it was just before Settings opened (the App's own screen only, never a gallery photo); app version, Android version, device manufacturer and model; screen information (fold state, screen size, orientation, layout, rotation lock); the film in use, the film list (catalog) version, the device language setting; the App's own recent activity log (up to 200 lines, with file paths and e-mail-like strings removed on the device and again on the server).
  2. Not sent or stored: the IP address (the server does not store connecting devices' IP addresses), the install ID, accounts, the advertising ID, location.
  3. Purpose: used only to find and fix app errors; not provided to third parties.
  4. Retention: deleted automatically 180 days after receipt.
  5. Please do not write personal information in a report. To have a sent report deleted, use Section 10.

3. Information Stored on the Device

  1. Photos are saved to Pictures/Sunmini; originals kept for re-developing are stored in the App's private storage.
  2. Settings, owned films, trial counts, unsent usage statistics (up to 7 days), install analytics (install ID, install source, up to 10 days of counts) and bug reports not yet sent (up to 5, deleted once sent) are stored on the device. The install ID is deleted with the App or its data and a new one is created after reinstalling.
  3. Redeemed gifts are included in Android Auto Backup (Google account) so they can be restored after reinstalling.
  4. Uninstalling the App deletes all App-private data. Photos saved to the photo library remain until the user deletes them.
